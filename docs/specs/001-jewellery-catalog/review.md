## Технические решения и проверки разработчика

Не требуют выбора библиотеки/формата пользователем, если не меняют согласованное поведение.

- D01 / задача 01: версии React/Vite/TypeScript/Mantine, браузерные targets, маршрутизация и открытие вложенных экранов на статическом хостинге.
- D02 / задачи 01 и 04: матрица iPhone/Safari/PWA и Android/Chrome; минимальные версии определить проверкой, а не обещанием «любая версия». Уточнить наличие устройств для ручной проверки при подготовке тестов.
- D03 / задача 02: снимки полей и справочных подписей, согласование встроенных и пользовательских значений, версия схемы, правила нового типа поля и устаревших вариантов.
- D04 / задачи 02–03: снимок шаблона при открытии формы; предложение — не менять уже открытую форму вслед за шаблоном. Одновременные вкладки не должны молча перезаписывать более новую запись.
- D05 / задача 03: поддерживаемые форматы фото, ориентация, декодирование и лимиты после измерений. Не вводить скрытое сжатие ради скорости.
- D06 / задача 04: ZIP/библиотека/имя файла, лимиты распаковки, совместимость старых копий, обработка отмены сохранения файла. Предложение имени: jewellery-box-YYYY-MM-DD.zip.
- D07 / задача 04: согласованный снимок коллекции для экспорта; конкурентные записи во время восстановления; атомарность данных и переносимых настроек, очистка производных кэшей.
- D08 / задачи 02 и 04: миграции базы и ошибки обновления; неизвестную версию копии отклонять без изменений. Поддержку старых версий задавать явной таблицей по мере появления версий.
- D09 / задачи 01 и 04: постоянный HTTPS-адрес, базовый путь, иконки/manifest, обновление оболочки. Публикация ещё не выполняется.
- D10 / задача 03: воспроизводимый набор из 100 записей с указанными размерами/количеством фото; по замерам определить приемлемые время загрузки и память.

## Что уже решено — не спрашивать повторно

Mantine и Mantine Form; React/TypeScript/Vite, CSS Modules и Dexie; отсутствие backend; несколько фото без обработки качества; несколько видов камней; общие поля плюс поля по типам; изменения шаблона только для новых карточек; темы и три семейства акцентов; системная тема по умолчанию; удаление с подтверждением без корзины; восстановление с полной заменой для переноса; цена и поиск отложены.
