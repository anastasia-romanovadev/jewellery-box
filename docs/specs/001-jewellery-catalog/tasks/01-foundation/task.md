## Результат

Адаптивный каркас личной шкатулки, единая тема и правила качества. Простой удобный интерфейс с акцентом на фотографии.

## Согласовано

- React, TypeScript, Vite, CSS Modules; Dexie для последующего хранения. UI-kit — Mantine, формы — Mantine Form.
- Молочная светлая тема, коричневая тёмная; системная по умолчанию, доступны ручные режимы.
- Акценты: приглушённый красный ближе к бордовому, зелёный и охра. По умолчанию — бордовый; точные оттенки подобрать на прототипе.
- Простой читаемый шрифт для всего интерфейса, включая заголовки.
- Навигация в сайдбаре: коллекция с подкатегориями и настройки. Настройки включают тему, шаблон и инструкцию установки. Нижняя панель вкладок не используется.
- Инструкция простая, пошаговая. В коллекции — заметная закрываемая плашка «Как установить на телефон»; в настройках инструкция доступна постоянно.
- В первую очередь мобильная версия, приоритет iPhone; также базовая адаптация для десктопа. Минимальные версии определить по возможностям выбранного стека.

## Адаптивное поведение, согласованное по прототипу

На мобильном сайдбар открывается кнопкой поверх содержимого, закрывается после выбора раздела, кнопкой закрытия или Escape; на широком экране расположен постоянно слева. Коллекция использует доступную ширину, формы ограничены по ширине для удобного чтения.

## Исправления аудита — 2026-11-19

Mantine использует тот же режим темы, что и приложение, включая первый запуск и смену системной темы. Мобильное меню управляет фокусом, блокирует фон и прокрутку; категории доступны в сайдбаре. Раздел шаблона содержит пояснение о будущем редакторе полей вместо неработающего выбора раскладки. Цены удалены из демоданных и карточек. Ошибка записи настроек показывается с повторной попыткой; старый JSON-кэш читается без обязательной перезаписи при запуске. Коллекция использует доступную ширину; настройки ограничены по ширине. Общие интервалы, размеры элементов управления и декоративные цвета вынесены в токены.

Автотесты проверяют поведение темы, навигацию, фокус, доступное имя закрытия диалога, восстановление кэша и ошибку записи. Они не подтверждают визуальную раскладку: пункты 01.7, F-02, F-04 и F-06 остаются открытыми до браузерной проверки 320/390/1440 px, текста 200%, обеих тем и сенсорного ввода. Физические устройства не проверялись.
