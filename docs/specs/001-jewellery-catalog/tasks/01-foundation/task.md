## Результат

Адаптивный каркас личной шкатулки, единая тема и правила качества. Простой удобный интерфейс с акцентом на фотографии.

## Согласовано

- React, TypeScript, Vite, CSS Modules; Dexie для последующего хранения. UI-kit — Mantine, формы — Mantine Form.
- Молочная светлая тема, коричневая тёмная; системная по умолчанию, доступны ручные режимы.
- Акценты: приглушённый красный ближе к бордовому, зелёный и охра. По умолчанию — бордовый; точные оттенки подобрать на прототипе.
- Простой читаемый шрифт для всего интерфейса, включая заголовки.
- Навигация в сайдбаре: коллекция с подкатегориями и настройки. Настройки включают тему, шаблон и инструкцию установки. Нижняя панель вкладок не используется.
- Инструкция простая, пошаговая. В коллекции — заметная закрываемая плашка «Как установить на телефон»; в настройках инструкция доступна постоянно.
- В первую очередь мобильная версия, приоритет iPhone; также базовая адаптация для десктопа. Минимальные версии определить по возможностям выбранного стека.

## Предлагаемое адаптивное поведение

На мобильном сайдбар открывается кнопкой меню поверх содержимого и закрывается после выбора раздела; на широком экране расположен постоянно слева. Коллекция использует доступную ширину, формы ограничены по ширине для удобного чтения. Это техническое предложение для прототипа, детали ещё не согласованы.

## Приёмка

- F-01: первый запуск соответствует теме устройства и использует бордовый акцент; ручной выбор сохраняется; системный режим реагирует на смену темы устройства.
- F-02: тема действует на поля, кнопки, диалоги и страницы. Ошибка различима не только цветом, в том числе при красном акценте.
- F-03: коллекция с подкатегориями и настройки доступны через сайдбар; шаблон находится в настройках. Плашка установки в коллекции закрывается, инструкция после этого остаётся доступна в настройках.
- F-04: нет горизонтального скролла страницы; элементы доступны пальцем и клавиатурой, текст читаем.
- F-05: build, lint и проверка типов проходят; зависимости и ограничения документированы.
- F-06: интерфейс адаптирован к мобильному и десктопному экранам, навигация не перекрывает рабочую область после закрытия меню; везде используется простой читаемый шрифт.

Вне задачи: функциональный редактор шаблона, данные украшений, импорт и service worker.
