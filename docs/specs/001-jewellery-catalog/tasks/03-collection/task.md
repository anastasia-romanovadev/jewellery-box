# 03. Коллекция и фотографии

Дополнение: подвески доступны во всех списках типов; порядок категорий согласован в spec.md. Аналитика по металлу показывает вес по пробам или типам, учитывает сочетания цветов золота один раз, исключает сочетания разных металлов и поясняет это. Пять статистических подписей сайдбара сменяются при открытии. Приёмка: создание/просмотр подвески, обновление после изменений карточки, независимость от фильтров коллекции, правильные суммы и пустые состояния, узкий экран и обе темы.

Уточнение 2026-11-23: каждому выбранному материалу соответствует отдельное поле пробы с его названием. Без материалов поля проб скрыты. Значения сохраняются независимо; удаление материала удаляет только связанную с ним пробу. Подробнее — spec.md.

## Решения пользователя — 2026-11-20

- Проба выбирается из общего справочника для всех материалов; в настройках можно добавлять варианты. Начальный список: 375, 500, 583, 585, 750, 800, 830, 850, 875, 900, 916, 925, 950, 958, 960, 999.
- Типы изделий фиксированные: пользователь не создаёт новые типы. Поле типа всегда видимое и обязательное, скрытие недоступно.
- При смене типа размер следует новому типу: несовместимое значение очищается, формат ввода меняется; для броши размер не показывается. Это исключение из неизменности схемы карточки. Изменения выполняются в черновике; сохранённая карточка меняется только после успешного сохранения.
- Фильтры: металл, размер, камни и диапазон веса. Фильтр по пробе не входит в выбранный набор; категории в сайдбаре сохраняются.
- Пока используется ровная сетка.
- Максимум 5 фото на украшение; оригиналы не сжимаются и не перекодируются.
- При выходе из изменённой формы показывается предупреждение. После подтверждённого выхода черновик не хранится.

## Шаги

Решения разработчика по поручению пользователя (2026-11-20): новые записи сверху, порядок стабилен при редактировании; плитка показывает тип, материалы и вес. Фильтры между группами сочетаются через И, внутри материалов/камней — ИЛИ. Размер фильтруется по формату: диапазон чисел для колец или сантиметров, конкретный вариант для серёг; пустые значения не соответствуют активному фильтру. Обложка — первое фото, порядок меняется кнопками. При превышении лимита выбор отклоняется целиком с объяснением. Последнее обязательное фото можно удалить из черновика, но для сохранения нужна замена. Типы остаются встроенными (кольца, серьги, цепи, браслеты, броши, прочее); броши/прочее без размера. Форма открывается в полноэкранном диалоге на телефоне; выход требует подтверждения при изменениях, после выхода черновик уничтожается. Переименование/удаление встроенных типов в интерфейсе не предлагаются. Материалы, камни и пробы редактируются в справочниках. Физический iPhone недоступен в среде разработки; соответствующая приёмка остаётся открытой.

## Проверки реализации — 2026-11-20

105 модульных и 20 браузерных тестов, lint и production build проходят. Браузерные сценарии покрывают создание, перезагрузку, редактирование, фильтры, удаление, лимит фото, ошибку декодирования, отказ записи с сохранением формы, конфликт двух вкладок, обе темы и узкий экран с масштабом 200%. Репозитории проверяют атомарный откат карточек и фото, байты оригиналов, исторические схемы и миграцию v2 → v3.

03.7 выполнен на синтетическом наборе: 100 карточек × 3 Blob по 256 КиБ (75 МиБ); изображения 1×1 PNG с дополнением байтами. Проверяются загрузка метаданных и число чтений фото; это не измерение памяти декодирования настоящих снимков. Отчёт сохраняется Playwright как collection-benchmark.json. 03.8: удаление фото, предупреждения и конфликты проверены; EXIF-ориентация и HEIC на iPhone ещё не проверены. Камера/галерея физического устройства, реальные большие фото и пиковая память остаются частью приёмки.

Последний синтетический замер Chromium, viewport 390×844: отображение 100 карточек — 185 мс, первоначально прочитано 4 из 300 фотографий. Значения относятся только к этому запуску и набору 1×1 PNG; память не измерялась. Светлый и тёмный мобильные экраны дополнительно просмотрены по скриншотам.

## Мобильный просмотр — 2026-11-20

По запросу пользователя фотографии в карточке и полноэкранном просмотре переключаются горизонтальным свайпом. Кнопки «Предыдущее/Следующее» убраны. Индикаторы позволяют выбрать фото нажатием, клавиши стрелок сохраняют управление с клавиатуры. Вертикальная прокрутка и масштабирование остаются доступны; свайп не открывает фотографию как нажатие.

## Фильтры в диалоге — 2026-11-20

Фильтры открываются кнопкой в модальном окне без раскрывающей стрелки. Вес задаётся одной строкой «от [ввод] до [ввод]». Изменения применяются только кнопкой «Применить фильтры»; закрытие отменяет несохранённый выбор. Применённые варианты отображаются рядом с кнопкой, общий крестик сбрасывает все условия фильтра (категория сайдбара сохраняется). Неверные диапазоны блокируют применение.

## Исправления по ревью — 2026-11-20

Форма создания и редактирования использует подписи и порядок полей из снимка схемы, включая тип и фотографии. Единицы веса и размера добавляются из снимка отдельно от подписи. Названия встроенных полей в текущем шаблоне остаются фиксированными; переименование через настройки доступно только пользовательским полям. Регрессионные проверки охватывают исторические подписи в снимке, порядок, числовой размер и размер серёг, независимость старой карточки от текущего шаблона, скрытые фотографии и выход без предупреждения после отклонения файла. Проверки на физическом iPhone и измерения с реальными фотографиями остаются открытыми.
## Уточнение: отдельные пробы материалов

По запросу пользователя: скрывать пробы до выбора материала, создавать поле для каждого выбранного материала; сохранять и показывать пары материал/проба. Проверить независимые значения для двух цветов золота, удаление одного материала, повторное открытие, валидацию каждой пробы и совместимость старых карточек с общей пробой.

Выход из изменённой формы создания/редактирования через крестик, отмену, Escape или внутренний переход подтверждается модальным окном приложения: «Вы уверены, что хотите выйти без сохранения украшения?», кнопки «Остаться» и «Выйти без сохранения». Отмена сохраняет черновик и возвращает фокус. Неизменённая форма закрывается сразу; во время записи/обработки фото выход заблокирован. Для закрытия вкладки или перезагрузки остаётся стандартная защита beforeunload браузера.

Визуальное уточнение фильтров: металл, камни, формат размера и размер серёг выбираются тегами вместо выпадающих списков. Теги идут в строку с переносом по ширине текста; выбранные выделены акцентным цветом. Металлы/камни допускают множественный выбор и повторное нажатие снимает выбор; формат/размер серёг — одиночный. Сохраняются применение по кнопке, отмена черновика, исторические варианты, цветные камни, диапазоны и общий сброс. Проверить сенсорный и клавиатурный ввод, обе темы, 320px и отсутствие горизонтального переполнения.

Просмотр коллекции: незаполненные поля (в том числе пробельные заметки/пользовательские поля, пустые камни, размеры и пробы) скрываются вместе с заголовком. Под заголовком коллекции: «Здесь собраны все ваши украшения». Сохранение фото доступно в карточке и увеличенном просмотре: текущий оригинал или все фото карточки в порядке photoIds. На устройствах с Web Share файлов — системное меню, иначе скачивание текущего оригинала или одного ZIP всех оригиналов; отдельное скачивание доступно и при наличии системного меню. Оригинальные байты не изменяются; имена безопасны и уникальны; ошибки чтения/выгрузки видны, отмена системного меню не запускает скачивание. Фото читаются по запросу, object URL освобождаются. Листание свайпом сохраняется. Пагинация не добавляется: текущая галерея выводит все отфильтрованные карточки.
